# 📐 Calculadora de Áreas em Java

## 📌 Sobre o Projeto

Este projeto é um sistema desenvolvido em **Java** com o objetivo de calcular diferentes tipos de áreas geométricas de forma rápida e eficiente.

A aplicação permite ao usuário escolher uma figura geométrica e informar os dados necessários para obter o cálculo da área automaticamente.

---

## 🚀 Tecnologias Utilizadas

* Java ☕
* Programação Orientada a Objetos (POO)
* (Opcional) Interface via terminal ou GUI (Swing/JavaFX)

---

## 🎯 Funcionalidades

* 📏 Cálculo da área de diferentes figuras:

  * Quadrado
  * Retângulo
  * Triângulo
  * Círculo
  * Trapézio

* 🧮 Entrada de dados pelo usuário

* 📊 Exibição clara dos resultados

* 🔁 Menu interativo (caso seja via terminal)

* ❌ Validação básica de entradas

---

## 🧠 Conceitos Aplicados

O projeto utiliza conceitos importantes de programação:

* **Encapsulamento**
* **Classes e Objetos**
* **Métodos**
* **Estruturas condicionais (if/else)**
* **Estruturas de repetição (while/for)**

Cada figura geométrica pode ser representada por uma classe específica, tornando o código mais organizado e reutilizável.

## 📊 Fórmulas Utilizadas

* Quadrado → área = lado²
* Retângulo → área = base × altura
* Triângulo → área = (base × altura) / 2
* Círculo → área = π × raio²
* Trapézio → área = ((base maior + base menor) × altura) / 2
